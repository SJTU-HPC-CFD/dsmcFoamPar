## controlDict Compatibility Change

The first direct run failed at OpenFOAM v1706 time creation because this case
had a v2506-style entry:

```text
writeControl none;
```

OpenFOAM v1706 accepts:

```text
adjustableRunTime
clockTime
cpuTime
runTime
timeStep
```

Backup made before editing:

- `run/hyStrath/dsmcFoam+/xcx_test/zb-cylinder-react/omp8/system/controlDict.codex_bak_20260606_before_v1706_writecontrol`

Only one line was changed:

```diff
-writeControl none;
+writeControl runTime;
```

The case-specific time settings and current OMP/profile controls were kept:

- `endTime = 1.9920146682e-05`
- `deltaT = 6.640048894e-08`
- `sampleSteps = 10`
- `useOpenMP = true`
- `openmpThreads = 8`
- `profileSummary = true`
- `profileDetail = false`
- `collisionFastRng = true`

Because `writeInterval` remained equal to `endTime`, the run wrote the final
time directory `1.992014668e-05`.
