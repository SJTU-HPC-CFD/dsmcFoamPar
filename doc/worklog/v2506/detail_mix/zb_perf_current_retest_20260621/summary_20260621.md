# zbcase 300-step performance retest, 2026-06-21

## Scope

This retest uses the saved controlDict snapshots from
`doc/worklog/v2506/detail_mix/zb_perf_cache_repair_single_20260621/controlDicts`.

The live cases under `run/hyStrath/dsmcFoam+/xcx_test` were not used as the
source of truth, because at least `mpi2omp4` had been changed to a short smoke
configuration. Fresh copied cases were prepared under `cases/`, with the saved
controlDicts restored before running.

`MPI8origin` is skipped in this retest per user request. The attempted direct
`mpirun -np 8 dsmcFoam+` origin log is invalid because it ran without
`processor*` directories or `-parallel`; it was killed and must not be used for
performance comparison.

## Notes

- The pure MPI8 degradation seen in the previous cache-repair run is mostly
  removed in this retest: full evolve improved from 74.209 s to 68.610 s.
- MPI2xOMP4 is the fastest valid result in this retest by both full evolve and
  real time.
- OMP8 full evolve is close to the previous baseline, but external real time is
  higher; the profile-internal timing is the more stable comparison point.
- MPI8 remains slower than mixed MPI/OMP because move dominates and DLB/check
  overhead grows with rank count. In this run, MPI8 spent 54.474 s in move only,
  4.284 s in migration max, and 6.249 s in Phase C auto-DLB max.
